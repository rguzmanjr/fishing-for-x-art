# Fishing for x — art pack

Images for the Fishing for x: Pier Edition classroom game. The game loads them from GitHub Pages.

- `manifest.json` — tells the game where everything is and how it lines up
- `avatar/` — the angler, in layers (skin, shirt, pants, and shoes are light gray so the game can color them)
- `hair/` — 24 hairstyles (light gray, colored by the game)
- `hats/`, `rods/`, `fish/`, `decor/`, `scene/`

Don't rename or move files. The game finds them through `manifest.json`.
